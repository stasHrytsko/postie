# Outgrow (На вырост)

- **Статус:** в игре; перенесена из stazzi `apps/casual/outgrow` целиком (2026-11-13, решение автора про перенос Ready-игр).
- **Источник:** правила — stazzi `SPEC.md` (§3–5), уровни — `src/levels/levels.json`, решения — поле `opt` солвера stazzi (`tools/outgrow-solver.mjs`). История идеи — `IDEA.md` (stazzi `ideas/potential/81-na-vyrost.md`).

## Правила

- Поле со стенами и 2–5 ростками. У каждого цвета — число: каким размером территория должна закончить.
- **Тап по любой клетке цвета** — он растёт **одним слоем**: занимает все свободные клетки, соседние с ним по стороне (слой считается по полю до нажатия). Ход — один тап.
- Рост останавливают только стены и другие цвета. Растишь один цвет, чтобы «подрезать» другой.
- **Победа:** свободных клеток нет, каждый цвет ровно своего размера.
- **Поражение:** цвет перерос своё число (`overgrown`) или свободные клетки остались, но к ним прилегают только собранные цвета — любой тап перерастит (`stranded`). Тогда «Retry» (или «заново» в шапке).
- Тап по цвету, которому некуда расти, — покачивание, ход не тратится.

## Что на экране

- Счётчик ходов `Moves k` (без лимита) и строка целей: значок цвета + `size/need`, у собранного — галочка, у переросшего — красный.
- Поле: цвета из `Postie.PIECES` (A абрикос/треугольник, B голубой/круг, C шалфей/квадрат, D масло/ромб, E песок/крест), значок стоит на ростке; стены — `.cell.wall`.
- **Метки будущего слоя:** на свободной клетке — маленькие значки тех цветов, которые займут её следующим тапом (в stazzi — точки 10%; здесь мини-фигуры, чтобы цвет не был единственным каналом). Кнопка «Hide marks / Show marks», выбор запоминается на устройстве.
- Рост анимируется: клетка выезжает из соседней своего цвета (160 мс).

## Уровни и сложность

**50 уровней**, все из stazzi, в том же порядке (`levels.js`). Поля 4×4 (1–2), 5×5 (3–6), 6×6 (7–10), 7×7 (11–25), 8×8 (26–50). У каждого — решение солвера stazzi (`solution`, буквы по порядку тапов); `test.js` прогоняет все 50 через движок. Движок дополнительно сверен с движком stazzi на 10 000 случайных партий — расхождений нет.

**Сложность** (`difficulty`, для волны в письме) — по оценке солвера stazzi `cfg.score = minCuts + len/3 + 6·dead + 4·trapShare + 1,5·forced` (обязательные подрезания, длина решения, доля тупиковых первых ходов, доля ловушек, обязательный порядок):

| `score` | `difficulty` | Уровни |
|---|---|---|
| < 13 | 1 лёгкий | 1–6 |
| 13–25 | 2 средний | 7–18, 21–23, 26–27, 31–33, 36–38 |
| ≥ 25 | 3 трудный | 19–20, 24–25, 28–30, 34–35, 39–50 |

`best` нет: у stazzi нет минимального числа тапов (`opt` — решение с наименьшим числом подрезаний, а не самое короткое).

## Отличия от stazzi

- Экран на ките Postie: без попапов «How to play», победы и поражения stazzi (правила, «Well done» и «заново» рисует оболочка; поражение — строка под полем и кнопка «Retry»).
- Нет руки-подсказки на уровнях 1–2 и карточки-подсказки — в ките её пока нет.
- Точки будущего слоя заменены мини-фигурами цвета (правило Postie: цвет не единственный канал).
- Пятый цвет — песок с крестом (в stazzi — фиолетовый с шестиугольником; в палитре Postie фиолетового нет).
- Отмены хода нет, как в stazzi (решение автора stazzi 2026-11-03: только «Retry»).
- Правила и уровни не менялись.
