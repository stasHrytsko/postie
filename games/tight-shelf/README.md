# Tight Shelf (Тесная полка)

- **Статус:** в игре, после MVP. Перенесено из stazzi (`apps/casual/tight-shelf`: SPEC.md, `src/engine/shelfEngine.ts`, `src/levels/levels.json`) 2026-11-13.
- **Уровней:** 17 — все из stazzi, в том же порядке (1–15 — поле 4×4, 16 — 5×5, 17 — 6×6).
- **Таймер убран (решение автора, 2026-11-03).** Цель — 5 линий, поражение — текущей фигуре некуда встать. В stazzi таймер тоже снят (2026-11-05), цель там та же.
- **Источник идеи:** `IDEA.md` в этой папке.

## Правила
- Фигура = цвет (синий, жёлтый, коралловый) + форма (круг, квадрат, треугольник), 9 типов.
- У каждой клетки полки своё правило: пустая — любая фигура; с контуром формы — только эта форма; цветная (рамка и подкраска) — только этот цвет.
- Тап по пустой подходящей клетке ставит текущую фигуру («Now»); видно ещё три следующих («Next»).
- Три подряд (по горизонтали, вертикали или диагонали) с общим цветом **или** общей формой исчезают. Четыре в ряд — две тройки, считаются за 2 линии. Каскадов нет.
- **Победа:** собрано 5 линий. **Поражение:** текущей фигуре некуда встать — заново (↻). Игра не предупреждает заранее.
- Отмены хода нет (как в stazzi).

## Очередь
В stazzi очередь бесконечная, из «мешка» (все 9 типов перемешаны; кончился — новый мешок), генератор mulberry32, и сид случайный на каждую попытку (кроме уровня 1). **В Postie сид у каждого уровня фиксирован** (`seed` в `levels.js`) — каждая попытка уровня получает ту же очередь, исход не зависит от случайности. Уровень 1 — сид 26, как в stazzi (обучающая очередь: три жёлтые фигуры подряд). Для остальных взят наименьший сид от 1, на котором бот с превью (порт `tools/bot.ts` stazzi: видит текущую и две следующие, любит линии и свободное место) набирает 5 линий; его ходы — `solution`.

## Уровни и сложность
- **`difficulty`** — по доле побед «слепого» бота (без превью: лучшая клетка только для текущей фигуры, линии в первую очередь, затем свободное место — бот `blind` из солвера stazzi) на 400 очередях подряд (сиды 1–400), без таймера: ≥ 0,9 → 1, ≥ 0,6 → 2, иначе 3. Бот с превью выигрывает почти всё и уровни не различает.
- Итог: 1–4, 16, 17 — лёгкие (поля с джокерами и большие поля: бот 97–100%); 5–10 — средние (74–84%); 11–15 — трудные (10–47%). Это совпадает с кривой stazzi: джокеров 12 → 0 на 1–10, дальше «сложнее сама доска», а большие поля — для разнообразия.
- **`best`** не задан: оптимума по числу ходов у игры нет.
- **`solution`** — клетки по порядку; `test.js` проверяет, что каждый тап легален и пятая линия набирается ровно на последнем.
- `tools/make-levels.js` пересобирает `levels.js` (`node games/tight-shelf/tools/make-levels.js > games/tight-shelf/levels.js`, около минуты).

## Что на экране
Сверху «Now» (крупно) и «Next» (три), под ними «Lines k / 5 · Pieces n», полка. Вид — по UI kit (`archive/design-v1/ui-kit-sheet.webp`, старый кит, Tight Shelf): фигура — сама форма, залитая цветом; клетка-форма — контур формы; клетка-цвет — рамка и подкраска цвета. **Цвет не единственный канал:** у фигур белые точки по цвету (синий 1, жёлтый 2, коралловый 3), у цветных клеток — те же точки.

## Отличия от stazzi
- Нет таймера и «+5 секунд» (в stazzi тоже убраны), игра заканчивается победой на 5 линиях (в stazzi после цели можно было продолжать).
- Фиксированная очередь на уровень вместо случайного сида на попытку.
- Цвета — токены Postie (blue, butter, apricot) вместо `#6294e9`, `#f4c05a`, `#ea7d60`; добавлены точки-метки цвета.
- Нет руки-подсказки на уровне 1, попапа «How to play» с картинками, звука; правила — текстом «?».
- Движок — чистый JS (`engine.js`), сверен со stazzi на решениях всех 17 уровней (поле, очередь, линии совпадают ход в ход).

## Открытые вопросы
- Нужна ли отмена хода: при фиксированной очереди она сильно облегчает игру.
- Сложность — по боту, не по плейтесту.
- Фиксированная очередь — её можно выучить; если важно, давать новую очередь на каждый день письма (сид от даты) — решение автора.
