# Arrow Flip

Карточка игры. Источник: stazzi `apps/casual/arrow-flip/` (SPEC.md, `src/engine/flipEngine.ts`, `src/levels/levels.ts`). Перенесено в Postie целиком 2026-11-13.

- **Статус:** MVP, ядро. **Уровней:** 25 — все уровни stazzi в том же порядке (1–4 на поле 4×4, с 5-го — 5×5; от 4 до 20 блоков).
- **Питч:** тапни блок — он уедет туда, куда смотрит стрелка. Каждый блок, которого он коснётся по дороге, поворачивается на 90° по часовой. Выведи все блоки за край поля.

## Правила
- Ввод — только тап по блоку. Блок едет по стрелке клетка за клеткой: за край — уходит с поля; упёрся в блок или камень — встаёт перед ним.
- Ход допустим, если блок сдвинулся хотя бы на клетку или ушёл за край. Тап по упёртому блоку — покачивание, ход не тратится.
- Задетые — все блоки, которые делят грань хотя бы с одной клеткой пути (старт и конец включительно, тот, в кого упёрся, тоже). Каждый поворачивается на 90° по часовой ровно один раз за ход. Сам едущий блок от касаний не поворачивается. Угол не считается.
- **Спецклетки** (из stazzi): **камень** (с 5-го уровня) — тёмная неподвижная клетка, не едет и не крутится, в него упираются; **вертушка** (с 9-го) — блок, въехав на неё, поворачивает на 90° по часовой и едет дальше (петля из вертушек обрывается — блок встаёт); **якорь** (с 13-го) — блок, стоящий на этой клетке, не поворачивается от касаний (уехать может).
- **Победа:** на поле не осталось блоков. Лимита ходов нет. Если ни один блок не может сдвинуться — строка «No block can move. Undo or restart.»; заранее игра не предупреждает, что уровень уже не пройти.
- Случайности и скрытой информации нет.

## Что на экране
Счётчик «Taps · Blocks left · Best», поле, под ним (если есть спецклетки) легенда, кнопка Undo. Цвет плитки — по направлению стрелки, как в UI kit (вверх — абрикос, влево — голубой, вправо — шалфей, вниз — butter); стрелка всегда нарисована, цвет её только дублирует. Камень — клетка Ink; вертушка — значок ↻ на клетке; якорь — белый якорь в углу блока. Проезд анимирован: едущий блок скользит по пути и растворяется за краем, задетые поворачиваются целиком (вся плитка, как в stazzi с 2026-11-10) в момент, когда он проезжает мимо. Тап во время хода запоминается и выполняется сразу после.

## Уровни и сложность
- Данные — `levels.js`: поле строками (`.` пусто, `^ > v <` блок, `#` камень), `spin` — вертушки, `anchor` — якоря.
- В stazzi у уровней нет решений и оптимума (генератор `tools/make-levels.ts`, зерно 36, «как ляжет», солвером не проверялись). Решения и `best` посчитаны солвером stazzi, перенесённым на движок Postie (`tools/solve.js`: поиск в глубину с растущим лимитом от числа блоков, это даёт минимум). Каждое решение дополнительно прогнано через движок stazzi — побеждает; движок Postie сверен с движком stazzi на 124 тыс. случайных ходов — расхождений нет.
- У всех уровней, кроме 5-го, `best` = числу блоков (каждый блок выходит одним тапом, если найти порядок); у 5-го — 12 при 11 блоках. Поэтому сложность считается не по длине решения, а по мере из SPEC stazzi §6 — **доля побед «случайного игрока»** (тапает случайный допустимый блок; 4000 попыток, фиксированное зерно): ≥ 75 % → 1 (лёгкий), 40–75 % → 2 (средний), < 40 % → 3 (трудный). Итог: лёгкие — 1, 2, 4, 9, 13; трудные — 5, 6, 7, 18, 22, 24; остальные средние. Пересчитать: `node games/arrow-flip/tools/solve.js`.
- Проверка: `node tests/run.js arrow-flip` — решение каждого уровня проходит ровно за `best` тапов.

## Отличия от stazzi
- **Уровень 14 исправлен:** в stazzi блок на якоре в углу (0,0) смотрит вправо в камень. Он не может ни сдвинуться, ни повернуться (якорь), и уровень непроходим (полный перебор это подтвердил). В Postie этот блок смотрит вниз (`v`) — единственная правка в данных; уровень решается за 17 тапов.
- Есть **Undo** (в stazzi отмены не было). Тупик не считается проигрышем: попапа поражения нет, только строка-подсказка и Undo / Restart.
- Показываем **Best** (в stazzi «Best» не показывали, оптимум не считали).
- Нет звука, конфетти, тёмной темы, руки-подсказки и попапов «New: …» про спецклетки; вместо них — постоянная легенда под полем на уровнях со спецклетками.
- Нет замков на уровнях, звёзд, «Your moves» на карточке уровня — экран уровней и «Well done» рисует оболочка Postie.
