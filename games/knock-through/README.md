# Knock Through (Перепланировка)

- **Статус:** в MVP, ядро (дедукция). Перенесена из stazzi `apps/midcore/knock-through` 2026-11-19 — **только голая механика** (решение автора: «убираем лишний визуал, доп бонусы и плюшки»). Нет забега, заказов с площадями в м², оплаты, магазина, бустов, несущих стен, капризов («у окна»), разлетающейся стены. Идея — `IDEA.md` (ядро — §2–5).
- **Похоже на:** Fillomino наоборот — границы не рисуешь, а стираешь, числа комнат складываются.

## Правила

- Поле нарезано на маленькие комнаты; в каждой написано, сколько в ней клеток. Сверху — **заказ** (например, 8 · 4 · 4).
- **Провести пальцем из комнаты через стену в соседнюю** — стена исчезает, комнаты становятся одной, числа складываются.
- **Цель:** комнаты на плане совпадают с заказом один в один.
- **Застрял:** комната больше любого числа заказа или не осталось стены, после сноса которой комната влезает в заказ — строка «застрял» с Restart. Дальше игра проигрыш не предсказывает.
- **Undo** — возвращает последнюю снесённую стену (решение автора 2026-11-19: отмена во всех играх).

## Что на экране

- Заказ — кружки-фишки с числами; фишка закрашивается, когда на плане есть комната такого размера.
- План: комнаты одного спокойного цвета (крафт; в Night — сине-серый), стены — толстые линии, число — в первой клетке комнаты; переросшая комната — красное число.
- Внизу Undo. Без анимаций и звука (п. 16 — в конце, со всеми играми).

## Обучение (`design/STRUCTURE.md` §5.6)

- **Уровень 0** (`view.js`, `tutorial`): 3×2, заказ 3 · 3 — 2 + 1 и 2 + 1; рука показывает оба сноса. Ловушка рядом: 2 + 1 по-другому оставляет 2 и 1 порознь.
- **«?»** — живое мини-поле: снос стены (1 + 2 = 3), потом уровень 0.

## Уровни — 100, генератор по `games/GENERATOR.md`

- **От ответа назад** (`tools/make-100.js`): поле режется на комнаты заказа, каждая — на маленькие комнаты. Снос стен внутри каждой комнаты заказа решает уровень — решаем по построению.
- **Солвер** (`tools/solver.js`): порядок сносов не важен — важно, какие комнаты окажутся вместе, поэтому решение = разбиение комнат на связные группы с суммами заказа (точное покрытие). Считает число ответов (`answers`, до 400) и долю стен, которые входят хоть в один ответ (`good`; остальные первые сносы — ловушки). Миллисекунды на уровень.
- **Ступень** — из числа комнат и ловушек (среднее, вверх); письмо: 1–2 лёгкий, 3–4 средний, 5–6 трудный. Сейчас 23 лёгких, 42 средних, 35 трудных; ступень 6 не выпала ни разу — трудные пятой ступени.
- **Кривая:** 1–8 маленькие поля (3×3, 4×4), 9–90 волна (4×4 → 5×5 → 6×6), 91–100 — 7×7.

```
node games/knock-through/tools/make-100.js k n     # воркер k из n → tools/out/slot-N.json
node games/knock-through/tools/make-100.js write   # → levels.js
```
