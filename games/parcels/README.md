# Parcels (Посылки) — вместе с Pair Up

- **Статус:** в MVP, ядро (дедукция). **Слита с Pair Up 2026-11-19 (решение автора):** база — Parcels (рамка → посылка уходит → всё сверху падает), правило пар из Pair Up живёт в ней как кубики с точками. Папка Pair Up — `archive/games/pair-up/`. Бывший вид правил Cave In (камни, пустые клетки, уровень 31) убран: в одно правило не входит; история — `IDEA-cave-in.md`.
- **Источник:** цифры — stazzi `apps/casual/parcels` (SPEC §3–5, `levels.json`); точки — stazzi `apps/casual/pairs`. История идей — `IDEA.md`, `IDEA-cave-in.md`.

## Правила

Поле — склад кубиков, прижатый ко дну. Кубик простой, с числом или с чёрной / белой точкой. Пальцем тянешь **рамку** от клетки до противоположного угла и отпускаешь. Рамка допустима, если в ней только кубики (без пустот) и это **одно из двух**:

- **посылка с числом** — ровно одно число, точек нет, площадь равна числу;
- **посылка-пара** — ровно одна чёрная и одна белая точка, чисел нет, размер любой.

Посылка уходит, в её столбцах всё, что выше, падает на высоту рамки; другие столбцы не двигаются. Цель — отправить все кубики. Тупик — кубики остались, а допустимой рамки нет: строка «застрял» с Restart. Отмены хода нет (решение автора stazzi).

## Уровни (author 2026-11-19: сначала цифры, потом точки, потом и то и другое)

**55 уровней** (`levels.js`, поле `kind` — только для порядка, правило одно):

| № | kind | Откуда |
|---|---|---|
| 1–30 | numbers | stazzi Parcels, тот же порядок, решения — `opt` солвера stazzi |
| 31–40 | dots | Pair Up 1–10 (stazzi Pairs; 11-й с серыми точками не перенесён) — каждая клетка стала кубиком |
| 41–55 | mixed | генератор `tools/make-levels.js`, по 5 лёгких, средних, трудных |

**Сложность** одна для всех: доля первых рамок, после которых уровень ещё проходится (≥ 0,5 → 1, 0,25–0,5 → 2, < 0,25 → 3). Солвер `tools/solver.js` на 30 уровнях stazzi даёт ту же сложность, что солвер stazzi, — все 30 совпали.

С гравитацией уровни Pair Up стали легче: 8 из 10 — лёгкие (в Pair Up было 2 из 10).

## Генератор — `tools/make-levels.js`

`node games/parcels/tools/make-levels.js [mixedCount]` — пересобирает уровни с точками и смешанные, 1–30 не трогает.

- Случайно режет поле на прямоугольники (2…6 кубиков); каждый получает число = площади или чёрную и белую точку. Посылки, отправленные сверху вниз, очищают поле, поэтому **каждый уровень решаем по построению**.
- Случайные уровни почти все лёгкие. Средние и трудные — «восхождением» (как `climb-levels.mjs` в stazzi): разрез остаётся, метки двигаются внутри своих прямоугольников, число ↔ пара меняются, пока доля хороших первых ходов падает.
- Скорость: 5×5 — доли секунды на уровень, трудный 5×5 — секунды; 6×6 — до нескольких секунд на одну проверку, трудный 6×6 — минуты. Для 100+ уровней в день хватает 5×5 и запаса 6×6, посчитанного заранее.

`test.js` прогоняет решения всех 55 уровней через движок.

## Открытые вопросы

- Уровни с точками лёгкие: нужен ли «подъём» и для них (генератор умеет, сейчас взяты как есть из Pair Up).
- Цифры и точки в одной посылке запрещены — проверить на плейтесте, что это понятно без отдельного урока.
- Смешанные трудные уровни сейчас в основном 5×5; 6×6 считается медленно.
