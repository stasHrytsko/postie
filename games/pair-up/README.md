# Pair Up (Пары)

- **Статус:** в игре; перенесена из stazzi `apps/casual/pairs` целиком (2026-11-13). В stazzi — на витрине в Ready.
- **Источник правил:** stazzi `apps/casual/pairs/SPEC.md` §3–5 и движок `src/engine/pairsEngine.ts`. `IDEA.md` в этой папке — ранняя версия идеи (из `ideas/potential/78-pary.md`).

## Правила
- Поле `w × h` (4×4 … 6×6) с тёмными и светлыми точками (в stazzi — «чёрные» и «белые»). Покрыть всё поле прямоугольниками так, чтобы в каждом была **ровно одна тёмная и одна светлая точка**.
- Уровень 11 — серые точки: верный прямоугольник — ровно две серые и больше ничего.
- Прямоугольник: площадь ≥ 2, внутри поля. Новый, пересекающий нарисованные, убирает их; точное совпадение с нарисованным ничего не меняет. Тап по прямоугольнику убирает его. Каждое рисование и удаление — +1 ход.
- **Верность видна только на полностью покрытом поле** (решение автора stazzi 2026-11-03): тогда верные светятся, неверные — пунктир Bad и «!». Пока поле не покрыто, все прямоугольники нейтральные.
- Победа: всё покрыто и всё верно. Поражения нет.

## Экран и управление
Один палец: перетаскивание от клетки до клетки — прямоугольник с этими углами (палец за полем держит рамку на крайней клетке); тап — убрать прямоугольник. Кнопка Undo. Точки: тёмная — сплошной круг Ink, светлая — круг Card с ободком Ink, серая — ромб цвета Line (форма отличает её от круглых). Счётчик «Moves» и «Best».

## Уровни и сложность
**11 уровней** — все уровни stazzi (`src/levels/levels.json`, генератор `tools/gen-levels.mjs`; уровень 6 — уровень автора из IDEA.md, 11 — серые точки), в том же порядке. У каждого ровно одно решение — оно и есть `solution` (stazzi `opt`); `best` = число пар (по прямоугольнику на ход).

Сложность (`difficulty`) — по метрике солвера stazzi `lookSteps` (поле `look`): сколько раз нужно проверить кандидата «на шаг вперёд», когда правила «эту клетку накрывает только один прямоугольник» уже мало:
- 0 → 1 (лёгкий): уровни 1–2;
- 1–5 → 2 (средний): 3–6;
- 6 и больше → 3 (трудный): 7–11.
