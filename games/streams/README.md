# Streams (Русла)

- **Статус:** в MVP, ядро (дедукция). Перенесена из stazzi `apps/casual/rusla` (2026-11-13); 2026-11-19 — 100 уровней, сначала без запаса ходов. В stazzi — Gate 1 `approved` (2026-11-09), на витрине в Ready.
- **Источник правил:** stazzi `apps/casual/rusla/SPEC.md` §3–5 и движок `src/engine/rusla.ts`. `IDEA.md` в этой папке — ранняя версия идеи (из `ideas/potential/83-rusla.md`).

## Правила
- Поле `w × h` (3×3 … 6×5). Линия идёт от старта (тёмная точка) по соседним по стороне свободным клеткам; пройти клетку второй раз нельзя.
- Каждая новая клетка стоит 1 ход из **общего запаса**; капля `+X` — сначала −1, потом +X. При запасе 0 шагнуть нельзя.
- На уровнях с развилкой ствол идёт от старта до развилки (ромб), в стрелки и финиши не заходит. На развилке открываются 2–3 ветки: каждая начинается строго по своей стрелке (номер) и идёт к своему финишу (пунктирное кольцо с тем же номером), в чужие стрелки и финиши не заходит. Ветки ведутся в любом порядке, переключаться можно когда угодно — запас общий, поэтому их приходится чередовать.
- Ветка на своём финише закончена. Без развилки финиш обычный: линия, зашедшая в него, закончена.
- Провести пальцем назад по линии — отвести её на клетку: ход возвращается, капля забирается обратно. Ствол отводится, только пока ни одна ветка не начата.
- Победа: все клетки пройдены, каждая ветка на своём финише (без развилки — линия на финише). Поражения нет; при запасе 0 — надпись «Out of moves», линию можно отвести.

## Экран и управление
Один палец, перетаскивание: палец на кончик линии (на открытой развилке — на развилку) и ведём; быстрый жест добирает пропущенные клетки по прямой (до 8 за событие, как в stazzi). Кнопка Undo — шаг назад. Цвета веток — слоты `Postie.PIECES` 1–3 (абрикос, голубой, шалфей), ствол — Ink; второй канал — номер на стрелке, головке и кольце. Капли — плитка Butter с числом. Счётчик «Moves left» (запас) и «Cells k / N».

## Уровни — 100, по `games/GENERATOR.md` (решение автора 2026-11-19: **развилка на каждом уровне** — это главная фишка игры; сложнее — больше веток (до 3), капли с запасом, поле до 8×8)

| Уровни | Что |
|---|---|
| 0 | учебный (`view.js`): развилка 3×3, рука ведёт ствол в развилку и обе ветки |
| 1–8 | ствол + 2 ветки, без запаса, 3×3 → 5×5 |
| 9–30 | 2 → 3 ветки, без запаса, 4×4 → 6×5 |
| 31 | **учит капли и запас** (`teach` — рука до первой капли) |
| 32–80 | смесь: без запаса / с каплями (запас только до 6×6 — на больших полях он не отсекает пути), до 7×7 |
| 81–100 | финал, трудные: 8×8 с тремя ветками и 6×6 с каплями, где запас заставляет переключать ветки |

Проверено: у всех 100 уровней 2–3 ветки (2 — 64 уровня, 3 — 36), одиночных линий нет. Уровни с каплями приходят в письме только после 31 (`needs`). Сейчас 5 лёгких, 52 средних, 43 трудных — развилка сама по себе делает уровень не лёгким по мере, [проверить на игроках].

**Генератор** — `tools/make-100.mjs` (на основе stazzi `gen-levels.mjs`): сначала случайное покрытие поля стволом и ветками (ответ), уровень — его скелет; запас — минимальный, при котором ответ проходится. Солвер — `tools/solver.mjs` (stazzi `rusla-solver.mjs`, `energy: null` — без запаса). **Ступень** — из числа клеток и ловушек вдоль ответа (доля шагов, после которых покрытие ещё возможно, по моментам выбора); +1, если запас заставляет переключать ветки. Сейчас 14 лёгких, 68 средних, 18 трудных — середина толстая, [проверить на игроках].

## Вид (решение автора, 2026-11-19: «слишком много информации — убираем всё лишнее»)

- Без цифр и без фишек-стрелок. **Финиш** — кружок цвета своей ветки (кольцо, пока ветка не дошла; закрашен, когда дошла). Ветки: красная, синяя, зелёная; ствол — чернила.
- **Развилка** (переделана 2026-11-19, роль дизайнера): точка-узел и короткие отростки цветов веток в ту сторону, куда каждая пойдёт, той же толщины, что линии; бледные, пока ствол не дошёл. Ветка вырастает из своего отростка.
- **Старт пульсирует** (решение автора 2026-11-19): мягкое кольцо расходится от точки старта, пока линия с неё не ушла; при «уменьшить движение» — неподвижное кольцо.
- **Капли** — контур капли воды с «+N» на пустой клетке, без цветной плитки; взятая исчезает.

## Отличия от stazzi
- Движок переписан на чистый JS (`engine.js`), поведение то же: проверено случайными жестами против `rusla.ts` (480 000 жестов, расхождений нет), тест прогоняет образец каждого уровня жестами «кончик → клетка».
- Обучение — уровень 0 с рукой, рука на уровнях 9 и 31, «?» — живое мини-поле в три шага (линия, развилка, капли). Нет волны победы и вибрации.
- **Без запаса ходов** (`energy: null`) на первых уровнях и на части остальных — счётчик тогда не показывается. Убран счётчик «Cells» и «best».
- Добавлена кнопка Undo (в stazzi только отвод линии назад).
- Попап победы — общий Postie («Well done»), без оценки игры после последнего уровня.
