# Nest

Карточка игры. Источник: stazzi `apps/casual/nested-tangram/` («Матрёшка из кусочков», идея 87, версия 3 «три слоя»; `SPEC.md`, `src/engine/{geom,pieces,state}.ts`, `src/level.ts`, `tests/planted.ts`), перенесено 2026-11-13.

- **Уровней:** 11 (все из stazzi, тот же порядок): House, Fish, Fox, Boat, Cat, Tree, Arrow, Castle, Cottage, Robot, Rocket.
- **Питч:** танграм-картинка не влезает в свою рамку: какие-то куски собраны неправильно. Приблизь картинку, зайди в кусок, переложи его кусочки в его контуре, выйди. Кусок может состоять из кусков — заходи глубже.

## Правила
- Рамка-контур картинки (пунктирная тень) и сама картинка — один силуэт, он с рамкой не совпадает.
- **Тап по силуэту** — видны куски картинки на своих местах. **Тап по куску** — вход внутрь: у куска своя доска со своим контуром, его кусочки стоят, как сложены (с ошибками). Внутри видны только контур и дети куска.
- Слоёв до трёх: картинка → кусок → кусок куска (лиса → хвост → кусочек хвоста). Уровни на 2 и 3 слоя.
- Кусочки — фигуры классического танграма (малый, средний, большой треугольник, квадрат, параллелограмм); поле — клетки, разрезанные диагоналями на 4 четвертинки. Отражать нельзя.
- **Перетаскивание** ребёнка (кусочка или куска) — он встаёт на ближайшее свободное место (до 2 клеток от того, где отпущен; тень показывает куда). Дети не накладываются и не выходят за доску. **Тап по кусочку** — поворот на 90° (если не встаёт — сдвиг до 2 клеток, иначе на месте и доска покачивается). Составной кусок не поворачивают.
- **Zoom out** — только если кусочки куска касаются сторонами (углом не считается). Форма куска снаружи — это его кусочки, как они лежат внутри; если новая форма легла на соседа, кусок встаёт на ближайшее свободное место (по возможности вне контура).
- Кусок, в котором ещё есть что править, лежит «стопкой» (второй лист сзади); собранный — плоский. Собранный контур доски подсвечивается шалфеем.
- **Победа:** картинка открыта, её куски закрывают рамку ровно, каждый кусок на всех слоях цельный. Засчитывается любая такая сборка. Победа внутри куска возвращает на верхнюю доску.
- Проиграть нельзя, таймера нет; счётчик «Moves» считает перетаскивания и повороты. Undo откатывает любое действие (в том числе вход/выход).

## Уровни и сложность
- Уровни перенесены **с точными координатами**: дерево кусков, контуры (четвертинки) и стартовая сборка с ошибками — из `src/level.ts` stazzi. Скрипт `tools/make-levels.js` переводит их в компактный формат (описан в начале `levels.js`); проверено, что дерево, собранное из компактных данных, совпадает с stazzi на всех 11 уровнях.
- `solution` — список ходов (open, in, rot, mv, out), а не только итоговая раскладка. Итоговая раскладка — решение солвера stazzi (`tests/planted.ts`); ходы к ней строит планировщик в `tools/make-levels.js` (сначала глубокие куски, мешающие кусочки отодвигаются на свободное место), прогоняя каждый ход через движок Postie. Те же ходы, прогнанные через движок stazzi, тоже дают победу на всех 11 уровнях. Решение не оптимальное, поэтому `best` у Nest нет (в stazzi минимального числа ходов тоже нет).
- **Сложность** — по числу слоёв и числу кусочков танграма не на своём месте на старте (`wrong`): 2 слоя → 1, если `wrong` ≤ 7, иначе 2; 3 слоя → 2, если `wrong` ≤ 12, иначе 3. Получилось: лёгкие 1–2 (House, Fish); средние 6, 7, 9, 10; трудные 3, 4, 5, 8, 11. Пороги — мой выбор, не решение автора. Порядок уровней stazzi не по сложности (Fox на 3-м месте — трудный).
- Пересобрать: экспортировать `LEVELS` и `PLANTED` из stazzi в JSON и `node games/nest/tools/make-levels.js <file.json>`.

## Отличия от stazzi
- Экран на ките Postie: кусочки по виду — малый треугольник абрикос, средний голубой, большой шалфей, квадрат butter, параллелограмм ink; составные куски — абрикос/голубой/шалфей/butter по порядку. Второй канал — сама форма фигуры и «стопка» у составных.
- Нет «камеры» (плавного наезда 620 мс на кусок и отъезда с проявлением соседей); вход/выход — короткое появление доски (`popin`). Тап по силуэту картинки открывает её сразу (масштаб 0,86 → 1 без анимации).
- Подъём куска над пальцем при перетаскивании — на 1,4 клетки только для касания (в stazzi — весь кусок над пальцем с зазором 24 px); без вибрации.
- Добавлены Undo (в stazzi его нет) и счётчик ходов.
- Нет экрана «Как играть» с картинками — правила в общей плашке оболочки.

## Открытые вопросы
- Камера (наезд/отъезд) — в stazzi главный приём читаемости вложенности; нужно ли переносить её в Postie (и в приложении).
- Доска внутреннего куска такого же размера, как у родителя, поэтому маленькие куски внутри выглядят мелко на 390 px — обрезать доску до контура с полем 2 клетки (как в SPEC §2.3)?
- Порядок уровней: Fox (3 слоя, 17 ошибок) идёт третьим, раньше простых двухслойных Tree и Arrow — для письма это не важно (берётся по сложности), но для страницы игры стоит обсудить.
- 11 уровней при ежедневном письме кончатся быстро (генератор уровней, `CONCEPT.md` §8).
