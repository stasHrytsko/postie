# Игры

Папка под каждую игру Postie (решение автора, 2026-11-02). **С 2026-11-13 в папке игры лежит всё: документы, все уровни, движок, экран, иконка и тест.** Сайт (`web/`) берёт игры прямо отсюда (`web/games` — ссылка на эту папку). Этот же код идёт в приложение через Capacitor (`TECH.md`), игры не переписываются.

Игры с витрины stazzi в статусе Ready (больше 10 уровней) перенесены сюда целиком со всеми уровнями (решение автора, 2026-11-13). Движки переписаны на чистый JS без кита stazzi, экраны — на ките Postie (`web/kit/`). Правила stazzi к Postie не относятся.

## Что лежит в папке игры

| Файл | Что это |
|---|---|

## Один каркас для всех игр (решение автора, 2026-11-16)

Оболочка (`web/js/main.js`, функция `play`) рисует вокруг любой игры одно и то же; игре ничего из этого рисовать не надо (`design/STRUCTURE.md` §5):

- **Шапка** — назад, название и номер уровня, «?», «заново».
- **Обучение (решение автора, 2026-11-19; `design/STRUCTURE.md` §5.6)** — игра даёт оболочке, а руку, уровень 0 и карточку «?» рисует оболочка (`Postie.hand` в `web/kit/kit.js`):
  - `tutorial` — уровень 0: обычный уровень с `solution`, самый простой, 2–3 хода, показывает главный приём;
  - `demo: [{ say, level }]` — шаги карточки «?»: мини-уровень с `solution` (рука играет его сама) и одна строка (`<b>` для главного слова);
  - `gesture(root, move, level)` → точки жеста на странице (`clientX/Y`): одна — тап, две и больше — провести пальцем; по ним рука и показывает, и (в «?») сама делает ход настоящими событиями указателя;
  - игра зовёт `ctx.moved(move)` после каждого сделанного хода (для руки на уровне 0); в карточке «?» оболочка передаёт `ctx.demo = true`;
  - в уровне: `teach: true` — рука показывает первый ход его `solution` (новый приём); `needs: N` — уровень приходит в письме только после уровня N (сначала научить).
  - Пока игра это не дала — текст `rules` карточкой при первом заходе и по «?». Писать коротко: что сделать и каким жестом.
- **Счётчики** — `Postie.stat([...])` показывает только цели и лимиты (`Blocks left`, `Moves left`, `Lines 2 / 5`). Пары `Moves`, `Taps`, `Shots`, `Swaps`, `Best`, `Undo` и числовое `Pieces` кит выбрасывает: счётчики ходов и рекорды не показываем.
- **Сообщения** — игра пишет в свой элемент `.msg`; оболочка прячет его и показывает текст одной строкой под полем. Класс `msg bad` означает «застрял / не сошлось»: оболочка показывает ту же плашку с кнопкой **Restart** во всех играх.
- **Кнопки** — игра кладёт их в `h('div', { class: 'row' }, [Postie.btn(...)])`; оболочка переносит ряд вниз экрана. Свои `Retry` и переключатели вида (`Hide marks`) оболочка скрывает — их не добавлять.
- **Решено** — игра зовёт `ctx.win()`; попап рисует оболочка.
- **Размер** — оболочка вписывает поле в экран: сужает колонку игры и строит её заново, а если поле всё равно выше — уменьшает его целиком (`transform: scale`). Поэтому размер поля считать от ширины `root`, а координаты касаний — через `getBoundingClientRect()` самого поля, не через свои константы в пикселях. Игры, которым это не подходит, перечислены в `NOSCALE` в `web/js/main.js` (сейчас Carpet Layers и Perfect Fit) — их поле прокручивается.

## Общие правила для всех игр

- **Кит Postie** (`web/kit/kit.css`, `web/kit/kit.js`; плоский прототип перекрашивает токены через `web/kit/flat.css` и `web/js/main.js`): цвета только из токенов (Milk, Ink, Apricot, Sage, Blue, Butter, Line), фишки — `Postie.PIECES` (у каждого цвета своя форма: цвет не единственный канал), иконки — `Postie.icon`, формы — `Postie.shape`.
- **Один палец, не больше трёх жестов на всё приложение:** тап, перетаскивание, свайп (`Postie.swipe`, `Postie.drag`). Ни мультитача, ни долгого нажатия, ни двойного тапа.
- **Таймеров нет нигде** (решение автора, 2026-11-03). Где в stazzi был отсчёт времени — убран; счётчики, если нужны, считают ходы.
- Решение для теста есть у каждого уровня; уровни не выдумываем — только из stazzi (или из солвера, если в stazzi уровни генерируются).
- Игра не подсказывает проигрыш заранее; исход не зависит от случайности.
- Язык интерфейса — английский; документы — по-русски.
