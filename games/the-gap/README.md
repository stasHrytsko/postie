# The Gap

Карточка игры. Источник: stazzi `apps/casual/the-gap/` (SPEC.md, `src/engine/gapEngine.ts`, `tools/the-gap-levels.json`). Перенесено в Postie целиком 2026-11-13.

- **Статус:** MVP, ядро. **Уровней:** 16 — все уровни stazzi в том же порядке (TG-00 … TG-16; TG-08 в stazzi нет).
- **Питч:** скользи цветными квадратами к выходам, каждый ведёт в свою колбу. Колбы стартуют перемешанными, поэтому квадраты приходится доставать обратно, а это возможно, только пока свободна клетка у выхода.

## Правила
- Поле-сетка 3×3 или 4×3 со стенами, в рамке 2–4 пронумерованные щели-выхода; у каждого выхода своя колба (вместимость 2–3), часть колб на старте уже заполнена.
- **Свайп по квадрату:** он едет до упора (стена, другой квадрат, край). Если на последней клетке есть выход в сторону свайпа и в его колбе есть место — квадрат уходит в колбу и ложится сверху. Иначе остаётся на клетке. Ход допустим, если квадрат сдвинулся или ушёл в колбу (квадрат на клетке выхода уходит свайпом к щели без шага). Проехать мимо чужого выхода вдоль рамки — не считается.
- **Тап по колбе:** верхний квадрат выходит на клетку её выхода, если она свободна. Достаётся только верхний.
- Недопустимый ход не тратится.
- **Победа:** поле пусто, каждая непустая колба одноцветна, каждый цвет — ровно в одной колбе.
- **Проиграть нельзя** (решение автора stazzi, 2026-10-11): лимита ходов нет, тупиков в уровнях нет (генератор stazzi это проверяет). Ходы сравниваются с Best.

## Что на экране
Счётчик «Moves · Best», цели по цветам («▲ 1/3 ● 0/3» — сколько квадратов цвета уже лежит вместе в одной одноцветной колбе; собран — галочка), поле в рамке с номерами щелей (как «Boundary wall» в UI kit), колбы с номерами под полем, Undo. Цвет квадрата всегда с формой: слот 1 — абрикос/треугольник, 2 — голубой/круг, 3 — шалфей/квадрат (`Postie.PIECES`). Стена — клетка Ink. Пока палец ведёт квадрат, бледный «призрак» показывает, где он остановится, а колба, куда он упадёт, подсвечивается; ход — при отпускании.

## Уровни и сложность
- Данные — `levels.js`: поле строками (`.` пусто, `#` стена, `1–3` цвет), выходы `[x, y, dx, dy]`, вместимости, содержимое колб снизу вверх.
- `best` — оптимум солвера stazzi (`opt`), `solution` — сохранённое в stazzi оптимальное решение. Оптимум перепроверен полным перебором на движке Postie (`node games/the-gap/tools/solve.js`) — совпадает на всех 16 уровнях. Движок Postie сверен с движком stazzi на ~886 тыс. случайных ходов — расхождений нет.
- **Сложность — по длине оптимального решения:** `best` ≤ 9 → 1 (лёгкий: уровни 1, 2, 3, 5), 10–14 → 2 (средний: 4, 7, 9, 10), ≥ 15 → 3 (трудный: 6, 8, 11–16).
- Проверка: `node tests/run.js the-gap` — решение каждого уровня побеждает ровно за `best` ходов.

## Отличия от stazzi
- Есть **Undo** (в stazzi отмены не было).
- Цвета и значки — из кита Postie (в stazzi синий/коралловый/жёлтый с кругом/треугольником/ромбом).
- Нет руки-подсказки на уровнях 1–2, попапа «Как играть» с картинками, звёзд и «You» на карточке уровня; правила — текстом в плашке оболочки.

## Открытые вопросы
- Читаемость у игры самая низкая из ядра (в IDEA.md оценка 3 из 5): проверить обучение без руки-подсказки.
- 16 уровней при ежедневном письме кончатся за несколько недель — что письмо кладёт дальше (`CONCEPT.md` §11).
- Результат «Moves / Best» — нужен ли он в спокойной оболочке.
