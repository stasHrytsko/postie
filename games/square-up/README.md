# Square Up (Долги)

- **Категория:** дедукция (решение автора 2026-11-19, запасные): порядок тапов не важен — итог зависит только от того, сколько раз каждый отдал и забрал; по сути система уравнений на графе («игра в доллар», chip-firing).
- **Статус:** запасная (`POSTIE_BENCH` в `web/games.js`, в письма не приходит); перенесена из stazzi `apps/casual/square-up` целиком 2026-11-19 (решение автора: «перекинь игру с stazzi в postie», в запасные, из stazzi убрать).
- **Источник:** правила и уровни — stazzi `index.html` (блок «правила») и `tools/square-up-solver.mjs`; история идеи — `IDEA.md` (идея 91 stazzi, Gate 1 одобрен 2026-11-19).

## Правила

- Люди-кружки с числом монет, между соседями линии. Минус — должен.
- **Тап** по человеку — **отдать**: он отдаёт по монете каждому соседу (у него минус число соседей, у каждого соседа +1).
- **Долгий тап** — **забрать**: по монете у каждого соседа. Вокруг кружка заполняется кольцо, через 420 мс «забрать» срабатывает сразу; отпустил раньше — «отдать».
- **Победа:** у всех ровно 0. Уходить в минус по дороге можно.
- Попытка — ровно `limit` тапов (точки над полем), отмены нет. Тапы кончились, а нули не у всех — поле качается, остаётся конечная позиция, строка «Not everyone is at 0» и плашка Restart оболочки.

## Что на экране

- Точки тапов над полем (закрашенная — потрачена). Других счётчиков нет.
- Кружки: минус — абрикос, 0 — шалфей, плюс — голубой; знак числа — второй канал к цвету.
- Монеты летят по всем линиям тапнутого (320 мс), задетые кружки подпрыгивают.

## Обучение

- **Уровень 0:** пять человек в линию `−1 2 −2 2 −1`, два тапа «отдать».
- **Уровень 2** (`teach: 2`): здесь впервые нужно «забрать», рука показывает оба хода — тап и долгое нажатие.
- **«?»:** три шага — тап отдаёт, долгое нажатие забирает, все в ноль за свои тапы.
- Для руки в ките добавлен жест «нажать и держать»: точка `{ x, y, hold: true }` (`Postie.hand`).

## Уровни и сложность

**10 уровней**, все из stazzi, в том же порядке (`levels.js`, исходник — `tools/square-up-levels.json`). 4–8 людей, тапов 2, 2, 2, 3, 3, 4, 5, 5, 5, 5. У каждого — ответ солвера (`solution`); `test.js` прогоняет все через движок и перебором проверяет, что короче нельзя (`best` = `limit`).

**Сложность** (`difficulty`) — по тесту солвера на жадное правило «тапай самое большое число по модулю (плюс — отдать, минус — забрать)»:

| Жадное правило | `difficulty` | Уровни |
|---|---|---|
| проходит всегда | 1 лёгкий | 1–5 |
| может ошибиться при ничьей | 2 средний | 6–8 |
| не проходит | 3 трудный | 9–10 |

Солвер: `node games/square-up/tools/square-up-solver.mjs > games/square-up/tools/square-up-levels.json`, потом перенести уровни в `levels.js` (ещё не по паттерну `games/GENERATOR.md`).

## Отличия от stazzi

- Экран на ките Postie: без главного экрана, экрана уровней и попапов stazzi; поражение — строка и плашка Restart оболочки.
- Нет счётчика попыток (`Try`), журнала плейтеста (`?stats=1`) и подсказок текстом на уровнях 1–3.
- В stazzi на уровне 1 «забрать» выключено; здесь долгий тап работает везде.
- Цвета — токены Postie, числа тёмные (`--on`), а не белые.
- Правила и уровни не менялись.
