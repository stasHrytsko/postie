# Postie на Unity — техническая основа

**Версия 1.0 · 16 ноября 2026.** Только действующее. Прежняя версия (аудит игр в `stazzi`, сравнение аналитики, старые экраны) — `archive/TECH-UNITY-2026-11-02.md`.

## 1. Решения автора (2026-11-02)

- **Всё на Unity 6.3:** оболочка (письмо, коллекция, календарь) и игры, на C#.
- **Платформа MVP — нативные iOS и Android**, через сторы. PWA больше не цель.
- **Unity-проект — в этом репозитории, папка `unity/`.**
- **Язык приложения в MVP — английский**; документация — на русском.
- **Аналитика — Firebase:** Analytics, Crashlytics, Remote Config + A/B Testing, через Firebase Unity SDK.
- **MVP — всё локально, без сервера.**
- **Порядок:** сначала механика игр и логика всего (сейчас — плоский прототип в `web/`), потом арт **[решение, 2026-11-16]**. Unity — после того, как логика согласована.

## 2. Откуда переносим

- **Источник правды для игр — `games/<игра>/`** (контракт — `games/README.md`): `engine.js` — чистые правила, `levels.js` — все уровни с решениями, `test.js` — прогон решения каждого уровня через движок (`node tests/run.js`).
- **Источник правды для логики дня — `web/js/main.js`** (письмо, волна, марки, коллекция, календарь) и `design/STRUCTURE.md`.
- Генераторы уровней и солверы — офлайн-инструменты (JS/TS, `games/<игра>/tools/`); Unity читает экспортированный JSON. Генератор для «10 новых уровней в день» — **[открыто]**.

## 3. Как переносим игры

1. **Движок — чистый C#** без `UnityEngine`: состояние, ходы, проверка победы, отмена. Отдельная сборка (`.asmdef`) на игру, тесты NUnit без сцены.
2. **Уровни — экспорт из `levels.js` в JSON** (`StreamingAssets/levels/<игра>.json`), один источник.
3. **Проверка совпадения:** решения из `levels.js` — те же golden-последовательности; прогоняем их через C#-движок, как сейчас через JS в `tests/run.js`.
4. **UI игры — заново в Unity**, сначала плоский, как прототип.
5. **Контракт игры для оболочки:**

```csharp
public interface IPuzzleGame
{
    string GameId { get; }
    int LevelCount { get; }                      // из данных, не выдумывать
    void Begin(PuzzleRequest request);           // gameId, levelId, source: Letter | Collection
    event Action<PuzzleResult> Completed;        // levelId, elapsedSeconds, attempts
    event Action<PuzzleSnapshot> Exited;         // для восстановления после выгрузки
}
```

`elapsedSeconds` — только для аналитики; на марку время не идёт.

## 4. Unity-проект

| Что | Выбор | Почему |
|---|---|---|
| Рендер | URP, 2D Renderer | 2D-спрайты и UI без 3D |
| UI | uGUI + TextMeshPro | Предсказуемо на мобильных; UI Toolkit — можно пересмотреть |
| Ввод | Input System | Свайп между экранами, тап, перетаскивание |
| Тексты | Unity Localization | Язык MVP — английский; все строки сразу через таблицы |
| Уведомления | `com.unity.mobile.notifications` | Локальное напоминание о письме |
| Контент | JSON в `StreamingAssets` | Всё локально |

```
unity/Assets/Postie/
  Core/     # день: выдача 10 уровней, письмо и развилки, марки, отправка, коллекция, календарь, сохранение
  Shell/    # экраны: Today (письмо, задачи, конверт), Games, Letters, настройки
  UI/       # общие компоненты
  Games/<Game>/  Engine/ (чистый C#)  View/  Tests/
StreamingAssets/levels/  StreamingAssets/letters/
```

## 5. Данные и сохранение

- Модель дня — `CONCEPT.md` §6.
- Сохранение — JSON в `Application.persistentDataPath`, запись атомарная (временный файл, потом замена) + предыдущая копия.
- Дата письма — по локальному времени устройства. Защиту от перевода часов в MVP не делаем.
- Экспорт прогресса — файл через системное «Поделиться».

## 6. Платформа

- **Уведомления** — спрашиваем после первой отправки. iOS — системный запрос, Android 13+ — `POST_NOTIFICATIONS`. Одно напоминание в день, когда пришло письмо.
- **Аналитика** — события из `CONCEPT.md` §7; без рекламных идентификаторов и отслеживания между приложениями, без личных данных. Если не отслеживаем между приложениями, ATT на iOS не нужен.
- **Remote Config + A/B** — гипотезы без обновления в сторе (состав волны, тексты развилок и т. п.); значения по умолчанию лежат в приложении.
- **Хаптика** — iOS: UIFeedbackGenerator / Core Haptics через плагин; Android: `VibrationEffect`.
- **Возрастной рейтинг** — тёмный мир в письмах влияет на анкеты сторов; заполнить по `WORLD.md`.
- **Арт** — после механики; PNG @3x, Pixels Per Unit = 3.

## 7. Порядок работ
