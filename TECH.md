# Postie — техническая основа

**Версия 1.0 · 17 ноября 2026.** **Решение автора: выходим в сторы на Capacitor, а не на Unity — цель выйти быстрее.** Прежняя основа на Unity — `archive/TECH-UNITY-2026-11-16.md`.

## 1. Решение

- **Приложение = текущий веб-прототип (`web/` + `games/`), завёрнутый в Capacitor** — нативные приложения iOS и Android из одного кода. Игры не переписываются.
- Язык приложения в MVP — английский; документация — на русском.
- Всё локально, без сервера.
- Аналитика — Firebase (Analytics, Crashlytics, Remote Config) через плагины Capacitor.
- Уведомления — локальные, спрашиваем после первой отправки.
- Реклама и SDK издателей, если понадобятся, — через нативные плагины Capacitor; у редких SDK может не быть готового плагина, тогда нужна своя прослойка.

## 2. Что сделать **[открыто]**

- Проект Capacitor в репо, сборка iOS и Android.
- Сохранение: перенести с `localStorage` в надёжное хранилище устройства, плюс резервная копия.
- Шрифты — внутрь приложения, без загрузки из сети.
- Плагины: локальные уведомления, хаптика, Firebase, статус-бар и безопасные зоны.
- Работа без сети.
- Сборка для iOS требует Mac с Xcode.
