## 1. Дерево

```
Запуск
└── ГЛАВНАЯ — три экрана свайпом: Letters ← Today → Games, открывается на Today
    │
    ├── Today — ПИСЬМО ДНЯ
    │   ├── по центру: письмо есть / письма нет (уже отправлено)
    │   └── письмо → записка почтальона → [Go to puzzles]
    │       └── задачи, сетка 3 × 4 → уровень
    │           └── решено → попап [Next] / [Send letter]
    │               └── конверт и марки → [Send] → Today: письма нет
    │
    ├── Games — КОЛЛЕКЦИЯ
    │   └── игра → её уровни по порядку прихода → уровень
    │       └── решено → попап [Next]
    │
    └── Letters — КАЛЕНДАРЬ
        └── отправленный день → письмо и три марки
```

Уровней вложенности три: **главная → экран → уровень игры**. Подписи Letters · Today · Games видны только на главной.

## 2. Письмо (Today) [решение, 2026-11-16]

1. **Пустой экран, по центру одно:** письмо есть или письма нет (уже отправлено).
2. Нажал на письмо → **записка** почтальона. Внизу одна кнопка: **Go to puzzles**.
3. **Задачи — сетка 3 × 4** (10 задач). Цвет кружка — сложность; решённая закрашена. Под кружком — игра и номер уровня.
4. **После каждой решённой задачи — попап:** до трёх решённых — только **Next** (следующая нерешённая задача письма); с третьей — **Next** и **Send letter**; после десятой — только **Send letter**. На сетке задач **Send letter** тоже появляется после трёх.
5. **Send letter → конверт и марки:** игрок сам клеит три марки в любой очерёдности. Тап по марке — встаёт в следующее свободное место; тап по марке на конверте — снимается. Можно вернуться к задачам и прийти к маркам позже — наклеенное остаётся. Три наклеены — **Send**. Неиспользованные марки сгорают.
6. Отправил → на Today «письма нет». **Оставшиеся задачи дня — только через Games, письмо — только через календарь; с Today к ним не попасть.**
7. **После отправки** уровни проходить можно, но марки больше не собираются и отправить второй раз нельзя.
8. **Дослать вчерашнее письмо нельзя.**

### Что в письме
- **10 новых уровней:** случайно 1–5 лёгких, 1–5 средних, 1–5 сложных (вместе 9) и 1 самый сложный. Новые — которых у игрока ещё не было, независимо от того, решил ли он вчерашние.
- **Записка почтальона** открыта сразу. Первый день — знакомство; дальше — развилки по вчерашнему письму: отправил или нет, какие марки.
- **Марка** — за каждую решённую задачу письма: игра и номер уровня, цвет сложности.

## 3. Коллекция (Games) [решение, 2026-11-16]

1. **Сетка игр 3 в ряд, только пришедшие.** Игр, из которых ничего не приходило, на экране нет.
2. **Группировка только по играм**; разреза по дням нет — для дней есть календарь.
3. На игре: название и «решено / пришло»; в кружке — сколько уровней ещё не решено, всё решено — галочка **[принято]**.
4. Тап по игре → её уровни **в порядке прихода, номера 1, 2, 3…** по порядку прихода (не номер в исходном наборе). Этот же номер — в письме, в шапке уровня и на марке.
5. После решения — попап с одной кнопкой **Next**: следующий нерешённый уровень этой игры.
6. **Уровни попадают в коллекцию только после отправки письма.** Пока письмо у игрока, все сегодняшние уровни — только в письме (в первый день коллекция пуста). Не отправил — уровни дня попадают в коллекцию на следующий день **[принято]**.
7. Самый сложный уровень дня остаётся помеченным как самый сложный и в коллекции **[принято]**.

---

## 4. Календарь (Letters) [решение, 2026-11-16]

1. **Настоящий месяц**, листается назад до месяца первого дня; сверху — **сколько писем отправлено**, без «подряд» **[принято]**.
2. **У дня два состояния: отправил — закрашен; не отправил — пустой.**
3. Тап по отправленному дню — письмо почтальона и три марки в том порядке, как их клеили.
4. **Не отправил — письмо пропало**, прочитать его нельзя (даже если открывал); уровни дня переночевали в Games.
5. **Сегодняшний день ведёт на Today**; письмо дня живёт только там.
6. **Из дня к его уровням перейти нельзя** — календарь только про письма и марки.

---

## 5. Навигация

- **Назад** всегда возвращает на один уровень вверх.
- Из уровня выход ведёт туда, откуда пришёл: в задачи письма или в игру коллекции.
- Главная не сбрасывает положение (экран, прокрутка) при возврате.
- Прогресс сохраняется на каждом шаге.

---

## 6. Первый запуск

1. Заставка → Today, письмо уже пришло; отдельного приветствия нет **[решение]**.
2. Первая записка — знакомство с миром и с тем, как всё устроено **[решение]**.
3. Первая задача каждой игры — с правилами прямо на экране уровня **[принято; в прототипе правила открыты при первом заходе в игру]**.
4. После первой отправки — «Напомнить про письмо?» и системный запрос уведомлений **[решение]**.

## 7. Визуал прототипа [решение, 2026-11-16]

Максимально просто: белый экран, плоские цветные точки, текст, никакого арта. Сложность — цвет: лёгкий голубой, средний жёлтый, сложный красный, самый сложный чёрный. Марка — плашка «игра + номер уровня» цвета сложности. Арт — потом (`design/VISUAL.md`).
