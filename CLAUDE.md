# Postie — заметки для Claude

Сборник маленьких логических игр с ежедневной почтой от почтальона. **Название — Postie, в сторе «Postie — daily puzzles»** (решение автора, 2026-11-03). Репозиторий пока называется pocketpuzzle — не переименовываем без отдельного решения.

## Файлы

- `ROADMAP.md` — **главный список: 28 шагов до релиза в сторы (принят автором 2026-11-17). Идём по нему по порядку; закрытый пункт — отметить `[x]`, дату и итог в журнале, решение записать в профильный документ.**
- `CONCEPT.md` — **концепция: только действующие решения** (что это, цикл дня, принципы, платформа, метрики, открытые вопросы, соцслой на потом).
- `design/STRUCTURE.md` — **структура по шагам:** три экрана (письмо, игры, календарь), каркас уровня, навигация, первый запуск. Новые решения по экранам — сюда.
- `web/` — **прототип всей логики в облике Post / Night** (Vercel, проект `postie`, https://postie-jade.vercel.app; корневой `vercel.json` собирает `web/` в `dist/`): `index.html`, логика дня — `web/js/main.js`, вид — `web/kit/flat.css`, кит игр — `web/kit/kit.js`, `kit.css`; порядок игр — `web/games.js`; `web/games` — ссылка на `games/`. «test» в углу: все игры и уровни (каждый уровень по номеру из `levels.js`, вне цикла дня; решённое — отдельно, `S.all`), следующий день, решить 3, сброс.
- `games/` — **16 игр, 547 уровней**, у каждой папка `games/<игра>/` (levels.js, engine.js, view.js, icon.svg, test.js, README.md, IDEA.md; контракт — `games/README.md`). Проверка: `node tests/run.js` — решение каждого уровня прогоняется через движок.
- `WORLD.md` + `world/` — **мир:** ядро и видение автора, механика глазами мира, голос, табу; канон с ID (`timeline`, `places`, `people`, `postman`, `ciphers`, `notes`, `patterns`); черновик голоса писем — `world/letters-draft.md`; **характер почтальона** (какой он, почему так пишет, как отвечает на конверт, как пишет дальше) — `world/character.md` (черновик Claude, 2026-11-19; прочтение канона, автор правит). Одно письмо = один факт канона + один новый вопрос; противоречить канону нельзя.
- `TECH.md` — **техническая основа: Capacitor (решение автора, 2026-11-17, вместо Unity) — веб-прототип заворачивается в нативные приложения iOS и Android, игры не переписываются.**
- `design/LOOK.md` — **облик (решение автора, 2026-11-16): Post — светлый (бумага, чернила, авиапочтовая кайма, марки с перфорацией) и Night — тёмный; переключатель в углу главной.** Палитры, шрифты, мотив; токены — `web/kit/flat.css`.
- `RESEARCH.md` — исследования рынка и референсов (Almanac, отзывы, мета-слои, переписка с незнакомцами, философские опоры). Выводы, не решения.

## Действующие решения (подробно — `CONCEPT.md`, `design/STRUCTURE.md`)

- **В MVP — 12 игр, смесь с дедукцией в ядре** (решение автора, 2026-11-19). Дедукция: Streams (100 уровней: развилка на каждом уровне — главная фишка; дальше 3 ветки, капли с запасом, финал 8×8), Parcels (слита с Pair Up 2026-11-19; 100 уровней: сначала цифры, потом пара входит в цифры, финал 7×7; генератор — `games/parcels/tools/`), Knock Through (перенесена 2026-11-19 — голая механика без забега и бонусов; 100 уровней, генератор от ответа назад), Hidden Stones, Perfect Fit, Outgrow. Ходовые: Arrow Flip, Slide Out, The Gap, Carpet Layers, Shadow Step, Bracket. Bracket — перенести из stazzi. **Запасные:** Tight Shelf, Nest, One Each, Recruit Ladder, Square Up — дедукция: порядок тапов не важен (в `games/`, в письма не приходят — `POSTIE_BENCH` в `web/games.js`); Forward / Back, Add Up, идея Crown Fit — в stazzi. Генераторы и солверы почти всех игр — stazzi `apps/*/<игра>/tools/` (п. 10). **Новый генератор любой игры — по паттерну `games/GENERATOR.md`** (решение автора 2026-11-19: строить от решения назад, сложность — ступени по «сколько думать вперёд» и размеру, кривая уровней, после запуска — рейтинг уровней по игрокам). Paint Ladder — `archive/games/`.
- **Три экрана:** письмо (Today) ← → игры (Games), календарь (Letters); свайп, открывается на Today.
- **Каждый день — письмо почтальона и 9 новых уровней:** случайно 1–5 лёгких, 1–5 средних, 1–5 сложных; «самого сложного» нет. Уровни новые, независимо от того, решены ли вчерашние. **Сложность нигде не показана**, задачи лежат от простых к сложным. **Уровни будет делать генератор**; сейчас 547 (в письма идут только игры MVP; на сколько дней хватит — нужно проверить).
- **Плавный вход:** день 1 — три игры, день 2 +1, день 3 +1, день 5 +1, дальше по нарастающей (в прототипе +1 каждый второй день); первые пять дней — только лёгкие и средние; новая игра первые два дня — только лёгкие и средние.
- **Письмо:** Today — пустой экран, по центру письмо с состоянием (N of 3 solved…) и строкой «Send it today. Tomorrow it is gone» или «письма нет» → первый тап: записка почтальона → «Go to puzzles»; потом тап ведёт сразу к задачам, записка — по кнопке Letter → сетка 3×3 → после каждой задачи попап: Next и Back to puzzles; с третьей ещё To the envelope; после девятой — только он → конверт: игрок сам клеит 3 марки в любом порядке, можно вернуться к задачам → Send letter.
- **Марка** — за каждую решённую задачу письма: игра и номер уровня; лишние сгорают. **У марок должна быть логика, очень трудная для разгадки** — какая, автор думает. **Формы: кружок — задача или уровень, квадрат — марка.**
- **Почтальон отвечает на марки:** первый день — знакомство, дальше развилки по вчерашнему письму (отправил ли, какие марки). Лучшего письма нет. **Игра связь письма и марок не объясняет — игрок должен дойти сам.**
- **После отправки:** марок больше нет, второй раз не отправить; оставшиеся задачи — только через Games, письмо — только через календарь. **Не отправил — письмо пропало, дослать нельзя.**
- **Games:** только пришедшие игры, только по играм; на игре — только процент решённого; уровни нумеруются по порядку прихода (1, 2, 3…), тот же номер на марке. **Уровни попадают туда только после отправки письма** (не отправил — на следующий день).
- **Календарь:** настоящий месяц, сверху — сколько писем отправлено; **два состояния дня — отправил (закрашен) / не отправил (пустой кружок)**; тап по отправленному дню — попап: записка и конверт с тремя марками; сегодня ведёт на Today; к уровням дня из календаря не перейти. **Везде даты, не «день N».**
- **Облик — Post и Night** (`design/LOOK.md`): плоско, без текстур и арта; антиква — голос почтальона, гротеск — интерфейс; один мотив — авиапочтовая кайма на конверте; один акцент; цвет только у фишек внутри игр. Светлый и тёмный переключаются кнопкой на главной.
- **Обучение показом (решение автора, 2026-11-19):** у каждой игры **уровень 0** — учебный, при первом заходе, рука показывает каждый ход; рука на уровне нового приёма; **«?» на каждом уровне — живое мини-поле, рука играет сама, минимум текста** (`design/STRUCTURE.md` §5.6, контракт — `games/README.md`). Сделано в Parcels, Knock Through, Streams; остальные — по одной.
- **Один каркас для всех игр** (`design/STRUCTURE.md` §5, `games/README.md`): шапка, карточка правил при первом заходе, одна строка сообщений, одна плашка «застрял» с Restart, кнопки внизу, один попап «решено». **На экране только то, что нужно для прохождения: без счётчиков ходов, Best и прочего лишнего.**
- **Хук:** игрок не знает, что почтальон напишет завтра, и знает, что тот ответит на его марки.
- **Мир:** будущее; почтальон — сильный ИИ, оставшийся один, спрятанный спаситель, никогда не названный; игроки — сознания людей внутри Best Version; письма — его мысли, тяжёлые вопросы, неровные, непредсказуемые; мир без конца, слоёв-поворотов нет; компании — только прошлое мира. Подробно — `WORLD.md`.
- **Вопросы мира** (решение автора, 2026-11-17; `WORLD.md` §0.0): апокалипсис — не событие, а постепенный процесс? насколько объективно наше восприятие реальности? как отличить настоящее от искусственного? как быстро человек нормализует абсурд? как жить в мире, который больше невозможно объяснить? Игра не отвечает — почтальон спрашивает.
- **Без давления:** нет таймеров, стриков, рекламы внутри решения; один палец, четыре жеста: тап, долгий тап, перетаскивание, свайп (долгий тап — решение автора 2026-11-19, для Square Up).
- **Платформа:** Capacitor — нативные iOS и Android из кода `web/` + `games/` (решение автора, 2026-11-17: цель — быстрее выйти в сторы; Unity отменён); английский в приложении; всё локально; Firebase; уведомления — после первой отправки; светлая и тёмная темы; покупок нет, монетизация позже.
- **Позже — соцслой:** письма незнакомцам только через почтальона, раз в день, ответ завтра, анонимно, письмо запечатано головоломкой.

## Правила работы

- **Пушить в `main` всегда** — после каждой правки, **только в `main`**; других веток не создавать (решение автора, 2026-11-02). Сначала `git fetch`, пушить только fast-forward; если `main` ушёл вперёд — сказать автору, не затирать.
- **Новое решение автора — сразу в `CONCEPT.md` / `design/STRUCTURE.md` и сюда; заменённое — убрать**, а не копить рядом «было / стало». Старый текст живёт в истории git и в `archive/`.
- **Не смотреть в репо `stasHrytsko/stazzi` и не применять его правила**, пока автор не скажет. Исключение — по прямой просьбе автора за конкретным материалом.
- Отвечать автору по-русски, коротко, по-человечески.
- Не выдумывать цифры: прогресс, число уровней, проценты, отзывы. Нет данных — плейсхолдер в квадратных скобках или «нужно проверить».
- Не превращать примеры в правила: открытые вопросы — в `CONCEPT.md` §8.
- Отделять решения автора от выводов исследований и от предложений Claude: **[решение]**, **[принято]**, **[открыто]**.
- После правки прототипа — прогнать `node tests/run.js` и проверить поток в браузере (Playwright).
