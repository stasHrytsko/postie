# Письма почтальона

## Письмо **[решение автора, 2026-11-13]**
- Каждый день — **одно письмо почтальона**. **Открыто сразу** **[решение, 2026-11-16]**; первый день — знакомство, дальше развилки по вчерашнему письму: отправил ли игрок и какие марки наклеил.
- **Письмо — его мысли:** о жизни, об игроке, о пазлах, о мире. Маленькие куски, из которых собирается мир. Глав основной линии, слоёв-поворотов и сезонов нет (`WORLD.md` §0.2).
- **Почтальон отвечает на марки:** какие три марки игрок наклеил на вчерашний конверт — от этого текст сегодняшнего письма другой. **Каждый раз, когда конверт пришёл, в завтрашнем письме — одна фраза про него: какие именно марки на нём были** **[решение автора, 2026-11-19]**. Фраза называет сами марки (игра и номер, в том порядке, как наклеены) и добавляет одно замечание; замечает, не оценивает.
- **Лучшего письма нет:** все равнозначны, просто разные. Никаких наград за комбинации.
- **После неотправленного** **[принято автором, 2026-11-19; `character.md` §0, §9]**: первый день — одна служебная строка («проверил почтомат: работает»); второй подряд — про все комнаты и его сомнение; с третьего — обычное письмо, про конверт ни слова. Дни он не считает.
- **Не отправил — письмо пропало** **[решение, 2026-11-16]**: перечитать его нельзя; следующее письмо знает, что ответа не было, и не упрекает.

## Как письма получаются разными **[предложение]**
Письмо = **общая часть** (одинаковая для всех, идёт по порядку писем) + **живой абзац** про вчерашний конверт. Абзац берётся из запаса:
- **по игре** — несколько строк на каждую марку;
- **по рисунку выбора** — три одинаковые; все разные; новая игра впервые; вернулся к старой; одна и та же много дней.

На старт — примерно [60–80] коротких строк. Всё локально, без сервера. Прежняя идея «зерно установки выбирает тексты из пула» больше не нужна для писем; для шифров (`ciphers.md`) зерно можно оставить.

Вариант глубже: **марка — это место снаружи** (`places.md` P-11), и в ответ на марку он рассказывает про это место. Тогда выбор игрока решает, какую часть мира он узнает первой.

## Формат письма **[предложение]**

```
ID:        N-0001
Тип:       обрывок письма | пометка на полях | опись | запись почтальона | чужой почерк | скан места   (WORLD.md §6)
Часть:     общая | абзац по игре <id> | абзац по рисунку выбора <какой>
Для кого:  все | пул A / B / C… (по зерну)
Факт:      P-06 (какие факты канона использует)
Вопрос:    какой новый вопрос оставляет
Шифр:      C-0x или —
Текст:     ≈ 30 секунд чтения
```

## Правила текста
- **Не слежка** **[решение автора, 2026-11-03]**: без текстов на данных, которые игрок не присылал (время открытия и т. п.). Марки он прислал сам — на них отвечать можно. **Замечает, не хвалит, не оценивает.**
- **Подача — как святое писание (решение автора):** можно трактовать по-разному, никакой конкретики. Как визг тормозов ночью: услышал, а что случилось, дописывает воображение. **Образ точный, событие несказанное.**
- Один факт канона — **намёком**, не утверждением — + один новый вопрос. Канон конкретен и известен автору; письмо — нет.
- Понятна сама по себе; полный смысл — рядом с другими.
- Понятно с любого места: новый игрок может начать с любого письма. Не врёт; глубокое не объясняет в лоб.
- Почтальон не диагностирует игрока; зеркало без указки.
- В каждой — маленькая законченная радость: образ, деталь, странная фраза. Большинство игроков не будет копать; письмо должно радовать само по себе.

- **Вопросы — тяжёлые, не бытовые** **[решение автора, 2026-11-14]**: такие, над которыми думают и которые обсуждают. Через вещь, без терминов; без ответа и без поля для ответа.
- **Чередование непредсказуемо** **[решение автора, 2026-11-14]**: игрок не может угадать, каким будет завтрашнее письмо; расписания нет.
- **Не каждое письмо гладкое** **[принято, 2026-11-14]**: бывают простые дни без поворота.
